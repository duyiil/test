## 1. 概述

智测是一个软件测试与质量保障平台。仓库标题是「基于大语言模型智能体的软件自动化测试与质量保障平台」。已经落地的主路径是：维护项目和接口契约，生成测试用例，人工审核，由独立 Worker 对 HTTP 接口执行，用四种断言给出数据报告。配置了密钥时，生成和研判可以走 OpenAI 兼容接口，默认指向 DeepSeek；没有密钥时生成仍是 Mock，研判状态保持 unavailable，不把 Mock 说成模型分析。

技术栈以仓库里的依赖和镜像为准：

- 后端：Python、FastAPI、Pydantic、SQLAlchemy、Alembic、PostgreSQL、HTTPX、pytest。API 镜像是 `python:3.12-slim`。Phase 0 审计记录当时的开发机是 Python 3.12.3。
- 前端：React、TypeScript、Vite、Ant Design、React Router、Axios、TanStack Query、Zustand、ECharts。
- 部署：Docker Compose。镜像为 `postgres:16`、`python:3.12-slim`、`node:22-alpine`、`nginx:1.27-alpine`。
- Worker 轮询 PostgreSQL，没有 Celery，也没有 Redis。

### 一键 Docker 部署

[PR #7](https://github.com/duyiil/test/pull/7)，合并提交 `f8a01be`，时间 2026-11-04T12:02:11Z。标题：用一条命令启动智测的 Docker 编排。

`./scripts/install.sh` 在缺少 `.env` 时生成随机数据库口令、`ZHITEST_SECRET_KEY` 和管理员密码，密码只打印一次。API 等待数据库端口后执行一次 `alembic upgrade head`。Worker 等 API 健康后再启动，不重复迁移。Web 用 nginx 提供前端并代理 `/api`。演示服务在 Compose profile `demo` 中。

在这台 Linux 虚拟机上，`docker compose --profile demo down -v` 之后执行 `sudo ./scripts/install.sh --demo`，五个容器都是 healthy。`curl http://127.0.0.1:8080/api/v1/health` 返回数据库可用。经 Web 代理可以用生成的管理员账号登录。浏览器走查：登录、新建项目「容器演示」、Base URL 填 `http://sut:9000`、载入演示契约、Mock 生成、审核通过一条 `GET /api/products 正常响应`、执行、报告断言通过率 100%。随后在 Compose 固定把主机名 `sut` 放进允许名单之后，又执行了一次：Worker 请求 `GET http://sut:9000/api/products` 返回 200，任务成功，报告通过率 100%，研判状态为 unavailable。套接字当时只有 root 能访问 Docker，所以那次命令加了 `sudo`。macOS 和 Windows 没有再跑。

更早一次容器连不上 `postgres:5432`，是这台机器上 iptables-legacy 的 `FORWARD` 策略为 `DROP`，而 dockerd 写的是 nftables。把该策略改为 `ACCEPT` 后，容器之间的 TCP 可以连通。README 把这件事写成排查说明，安装脚本不去改宿主机防火墙。

## 6. 使用方式

前提：Docker Engine 或 Docker Desktop，并且当前用户能运行 `docker`。Windows 用 Git Bash 或 WSL。说明在 README 的「一键部署」。

```bash
./scripts/install.sh --demo
```

不需要演示服务时去掉 `--demo`。浏览器打开 http://127.0.0.1:8080 。用户名是 `admin`。密码在第一次生成 `.env` 时打印；错过了看 `.env` 里的 `ZHITEST_ADMIN_PASSWORD`。带 `--demo` 时，项目 Base URL 填 `http://sut:9000`。

停止用 `docker compose stop`。升级再执行 `./scripts/install.sh`，已有 `.env` 时不会重写密码。清空数据用 `docker compose down -v`。DeepSeek 密钥写在 `ZHITEST_LLM_API_KEY`，留空则生成仍是 Mock。

本地不用 Docker 时，按 README「本地运行」启动 API、前端，以及 `docs/phase2.md` 里的 Worker 和演示服务。那个入口的示例口令是 `ChangeMe-Admin-2026`，只用于本地开发。
