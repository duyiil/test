## 5. 已知边界（不允许在演示中夸大）

以下事项在本轮 Demo 中**不做、不声称完成**，演示话术须与此一致：

1. 生成是 Mock 版（读项目内保存的契约），不是真实 LLM；对应 AC-19 的"做实模型留待后续替代"。
2. AI 摘要/研判固定 `unavailable`，报告为降级的纯数据版；Mock 生成不会被写成 AI 分析结论。
3. 执行器只允许访问本机回环地址，不对服务器发起测试。
4. 移动端滑动审核、通知推送、缺陷自动建单等不在本次 Demo 主链路内（范围界定见《需求变更记录与 Sprint2 范围维护》）。
5. `demo/sut` 是作者自建的演示服务，其 7 处缺陷是故意埋入，不是团队原始 Demo 预埋的缺陷。
