## 2. Sprint2 范围维护

### 2.1 本轮范围内（Demo 验收口径）

- 载入演示契约 → Mock 生成 → 审核（通过/编辑/驳回，原因必填）→ 执行（Worker、4 类断言、写操作二次确认）→ 数据报告（降级版）。
- `demo/sut` 一键启动与 7 处差异观察。
- 本文件及《Demo 测试用例与执行记录》《Sprint2 验收标准确认 + 演示脚本与彩排》三份交付物。

### 2.2 本轮范围外（不得写入演示话术）

- 真实 LLM 生成与研判、token 用量统计。
- 移动端滑动审核（TC-REVIEW-006）。
- 通知外部推送（TC-NOTIFY 外部推送部分）。
- 缺陷自动建单与第三方同步（US-015、US-025）。
- 定时执行的系统级 cron、多环境变量链、Web/小程序驱动（Sprint4/5 范围）。
